# Motors

The **HSK-Mensabot** is driven by two integrated **JMC AC servo motors** equipped with planetary gearboxes, belt drives and electromagnetic holding brakes. The motors provide the propulsion for the differential drive platform and are controlled by an Arduino-based motor controller receiving velocity commands from the ROS2 hardware interface.

---

# 1. Hardware Overview

The propulsion system consists of two identical servo drive units mounted on the left and right side of the robot.

| Component | Description |
|-----------|-------------|
| JMC Servo Motor | Robot propulsion |
| Planetary Gearbox | Torque multiplication and speed reduction |
| Belt Drive | Mechanical transmission between gearbox and drive wheel |
| Electromagnetic Brake | Holds the robot when the drive is disabled |

The combination of servo motor, planetary gearbox, belt drive and holding brake provides precise motion control while ensuring safe operation during emergency stops and power loss.

# 3. Mechanical Drive System

The HSK-Mensabot uses a differential drive configuration consisting of two independently driven wheels and passive caster wheels for support.

Each drive wheel is powered by an integrated servo motor through a **planetary gearbox** followed by a **belt drive**. This combination provides a transmission ratio of **39.878 : 1**, increasing the available wheel torque while reducing the output speed. The belt drive transfers the torque to the drive wheel and allows the mechanical arrangement required by the robot chassis.

The integrated holding brake prevents unintended movement whenever the motors are disabled or the robot is switched off.

---

# 4. Electrical Connections

The servo motors are controlled using dedicated digital control signals generated by the Arduino motor controller.

| Connection | Purpose |
|------------|---------|
| Power Supply | Motor power supply |
| Pulse | Position and speed command |
| Direction | Rotation direction |
| Enable | Motor enable signal |
| Brake | Electromagnetic brake control |

The motor power supply is switched by the external **safety relays**, allowing the drives to be safely disconnected whenever an emergency stop or hardware safety event occurs.

---

# 5. Motor Control

Velocity commands generated by the navigation stack are converted into wheel velocities by the ROS2 Diff Drive Controller. The Hardware Interface translates these commands into a binary communication packet and transmits them to the Arduino via the serial interface.

The Arduino calculates the corresponding pulse frequency for each motor and generates the required pulse and direction signals for the integrated servo drives.

To reduce the computational load on the Arduino, the **Steps per Revolution** parameter of the servo motors was changed from the factory default value of **4000** to **50**. With the original configuration, the required pulse frequencies would have exceeded the processing capability of the Arduino for reliable pulse generation.

Despite this reduction, the positioning resolution remains more than sufficient for the mobile robot. Taking the gearbox ratio into account, the resulting wheel resolution is approximately **0.35 mm per pulse**, which is significantly finer than the mechanical accuracy required for autonomous navigation.

---

# 6. Brake System

Each servo motor includes an integrated electromagnetic holding brake.

The brake is automatically released when the motor is enabled and engaged whenever the drive is disabled or power is removed. This prevents unintended robot movement during emergency stops, power failures and maintenance operations.

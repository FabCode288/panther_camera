Safety Control Node
===================

The ``SafetyControlNode`` is the central software safety component of the HSK-MensaBot. It supervises the current safety state of the robot by combining information from the safety laser scanners, the hardware interface and the emergency stop circuit.

Based on the current operating state, the node publishes speed limitations, emergency stop information and filtered velocity commands. In addition, it performs the automatic reset of the safety relay once all safety conditions have returned to a valid state.

Purpose
-------

The node performs the following safety-related tasks:

* Monitors the front and rear safety laser scanners.
* Evaluates warning and protective field violations.
* Supervises the hardware connection state.
* Monitors the emergency stop relay.
* Automatically resets the safety relay after a valid release.
* Limits the maximum driving speed inside warning fields.
* Stops all robot motion during emergency stop conditions.
* Publishes the current emergency stop state for other software components.

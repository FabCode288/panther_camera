Velocity Transformation Node
============================

The ``TwistToStamped`` node converts velocity commands from the standard ROS 2 ``Twist`` message format into ``TwistStamped`` messages.

The transformation is required because the Safety Control Node publishes velocity commands as ``Twist`` messages, while the ros2_control Diff Drive Controller expects ``TwistStamped`` messages. During the conversion, a timestamp and the corresponding coordinate frame are added before forwarding the command to the controller.

Purpose
-------

The node performs the following tasks:

* Receives velocity commands from the safety layer.
* Converts ``Twist`` messages into ``TwistStamped`` messages.
* Adds the current ROS timestamp.
* Assigns the ``base_link`` coordinate frame.
* Forwards the converted command to the Diff Drive Controller.

Transformation
--------------

For each received velocity command, the node creates a new ``TwistStamped`` message by:

* Copying the received linear and angular velocities.
* Adding the current ROS timestamp.
* Setting the coordinate frame to ``base_link``.
* Publishing the resulting message to the robot controller.

Developer Guide
===============

The Developer Guide provides technical information for developers working on the HSK-MensaBot software project. It complements the User Guide by focusing on the internal project structure, software development workflow and documentation process rather than the operation of the robot.

This guide is intended for contributors who want to build the software, understand the repository organization or extend existing functionality. It also documents the tools and workflows used throughout the development of the project.

The Developer Guide is organized into the following sections:

- **Repository Structure**
  
  Describes the organization of the ROS 2 workspace and explains the purpose of the most important directories and project resources.

- **Build**
  
  Explains the software build process, required dependencies, workspace compilation and common development commands.

- **Documentation**
  
  Describes the documentation workflow based on Sphinx, Doxygen and GitHub Pages, including the generation and publication of the project documentation.

Together, these chapters provide the information required to efficiently develop, maintain and document the HSK-MensaBot software.
